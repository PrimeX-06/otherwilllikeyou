# 第三幕叙事过门生图资产

本目录的四张 `story_*_512.png` 是用现有学校场景和角色形象作参考生成，再按最近邻缩到 512×288 的**过门 CG**。对应：

- `story_g01_handoff_512.png`：周一通知、纸张与箱子递接；
- `story_g03_bench_512.png`：周五三人在走廊长椅猜人物；
- `story_g04_exit_512.png`：球赛结束、球停、收书包；
- `story_g04_to_corridor_512.png`：回走廊后朱里走向教室门，和臣与由乃留下。

`source/` 保留生成原图，便于后续裁切和精修。`story_g01_handoff_pose_01..04.png` 是四个双人动作关键姿势的参考，**不是** 48×72 透明精灵帧，也不能直接用作人物动画。做实际动画时需按原精灵表的比例、脚底基线和前后遮挡重绘。

使用边界：四张 CG 现在都已接入——`story_g01_handoff` / `story_g03_bench` 用作日期卡底图，`story_g04_exit` / `story_g04_to_corridor` 接在叙事收尾与 `?phase=after` 开头。现有 G03 猜题面板与 G04 球赛玩法保持原样。周五 CG 的人物在画面右后方，接 UI 时要避开那一块；球赛散场图是平视镜头，接 2.5D 玩法需要一次明确的镜头切换。生图中的远景建筑细节和道具形状仍应与最终游戏场景做一次并排美术校对。

重建 512×288 预览：项目根目录运行 `python tools/prepare_act5_story_art.py`。脚本读取本机生成图原路径；运行游戏只需本目录已保存的 PNG。
