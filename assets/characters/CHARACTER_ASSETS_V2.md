# 三人角色资产包 v2

朱里的闺蜜、和臣、朱里分别位于 `friend/v2`、`boy/v2`、`girl/v2`。每个目录包含：

- `*_sheet_v2.png`：透明背景，单帧 48×72，横向排列，可直接供 Canvas `drawImage` 读取。
- `manifest.json`：帧位、动画序列、脚底基线。新增动作统一命名为 `wave`、`talk`、`pickup`、`lean_left`、`sit_left`、`offer`、`shy`、`lean_back`。
- `frames/NN.png`：独立透明帧；`walk_*.gif`：便于审阅的循环预览；`*_contact_sheet.png`：总览。
- `source/`：生图原画，保留供重切或重绘。闺蜜原有九帧待机 GIF 仍在 `friend/friend_idle.gif`。

闺蜜共 36 帧：0–8 为原待机；9–11 为新侧面和背面；12–27 为四向行走；28–35 为剧情动作。右向行走由左向行走镜像得到。和臣共 31 帧、朱里共 33 帧：各自原有帧保持原位，剧情动作附在精灵表末尾，旧帧索引不变。

第二幕黑板报开场已用闺蜜的行走与挥手帧作短暂铺垫；通往广播室的过场用朱里的递稿帧。广播后的走廊使用男女主的说话帧与和臣的弯腰拾纸帧。第五幕也已改用三张 v2 表。其他镜头可按各角色 `manifest.json` 的索引调用。生成脚本：`tools/build-character-asset-packs.py`。

原画由 imagegen 依据项目既有角色形象生成，之后裁切、统一尺寸并装配为游戏帧。坐姿、弯腰和靠栏杆是静态关键姿态，尚未提供完整过渡动画；需要在具体剧情镜头里按动作节奏补中间帧。
