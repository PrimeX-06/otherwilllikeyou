# 第二幕 · 一起完成的黑板报

双击 `blackboard.html` 就能玩。不用构建、不用服务器、不用联网。

## 玩法

走廊开场 → 由乃（朱里的闺蜜）经过，和她打个招呼 → 镜头推近黑板 → 画 → 两个人站在板前看成果。旁白带出她是朱里常一起走的朋友；她只在开场短暂出现，使用侧面行走与挥手帧，为后面的校园日常出场铺垫。

| 操作 | 键 |
| --- | --- |
| 画笔 / 橡皮 / 直线 / 方框 / 文字 / 图案 | `B` `E` `L` `R` `T` `S` |
| 显示 / 隐藏预设底稿 | `G` |
| 换粉笔色 | `1`–`6` |
| 撤销 / 重做 | `Ctrl+Z` / `Ctrl+Shift+Z` |
| 移动放好的图案 | 用图案工具点住它拖 |
| 微调 / 删掉选中的图案 | 方向键（`Shift` 走 4px）/ `Delete` |
| 对白推进 | `E` 或点击 |
| 离开黑板（随时） | `Esc` 或左上角「离开」 |
| 完成（四区齐了之后） | 点「完成黑板报」或 `Enter` |

四个区都达标，完成按钮才会亮：

| 区域 | 达标条件 |
| --- | --- |
| 标题 | 标题区有字，且至少 2 个字是文字工具写上去的 |
| 边框 | 上、下、左、右四条边各有一半以上被画到 |
| 主图 | 中间画够了，且有一笔超过 40px |
| 装饰 | 下方装饰带或四角放够 3 个图案 |

**板上有层很淡的草稿**——设定上是朱里事先打的稿：虚线边框、标题下划线、主图区一张淡化的人像、
底下三个小圈标出图案该放哪。照着描就行，**画完一块，那一块稿子自己就淡掉**，四块都淡完，
板面上就只剩你们俩画的东西。它擦不掉、撤不掉、也不会进导出图。想从白板开始就按 `G` 关掉。

**图案是这一版的重点**。按 `S` 展开图案面板（花草 / 天空 / 校园 / 装饰 四组，18 个），
点一下板面就放下一个，跟着当前粉笔色走。放下之后它是**东西不是像素**：能拖、能方向键微调、
能被橡皮整个擦掉、能撤销。所以「放歪了再挪回来」这件事才成立。

朱里会自己补边框、往装饰区添图案、把挤在一起或压出格子的图案挪正、点星星、递粉笔。
她只在空白处落笔，不擦你的东西，挪图案时也只改位置、不碰你画的线，
一次辅助按一次 `Ctrl+Z` 就整笔撤掉，全局最多 6 次——她不会替你画完。

**画板期间她一直在说话**，走画布下面那条对白区：左边朱里、右边和臣，中间一个对话框，
谁说话谁亮起来、尾巴指过去，两个人还会错开眨眼。整条在画布**外面**，黑板一点都不被挡。
内容大部分是日常闲聊（抽卡、开黑、追的选秀、食堂、月考、周末），只有少数几句和这块板有关——
干活时聊的本来就是这些零碎事。她补完边框、你擦掉东西，那些事件台词也走同一条。
结尾那几句也在这儿，按 `E` 推进，读完两个人才退场、完成卡才出来。

**随时可以走**。按 `Esc` 或点左上角「离开」，她会说一句，画面压暗，推出「先到这儿」卡：
「接着画」回板前，「离开」跳回去（默认 `../school-preview.html`，接宿主时用 `?back=` 指定）。
走之前一定存盘，下次进来接着这张画。

## 文件

| 文件 | 作用 |
| --- | --- |
| `blackboard.html` | 入口。普通 `<script>`，`file://` 直接能跑 |
| `board.css` | 界面。工具栏和对白区都在画布**下面**，图案面板展开时画布自己缩小 |
| `board.js` | 板面本体：几何、粉笔渲染、预设底稿、分层、图案对象、历史、四区判定、导出、存档 |
| `ghost-art.js` | 主图底稿那张画稿，base64 内嵌成 data URL（`file://` 下不用处理跨域） |
| `ghost-main.png` | 上面那张画稿的源文件，128×128，粉笔色 + alpha |
| `patterns.js` | 18 个预设图案，点阵画法，三色调，跟着粉笔色走 |
| `girl.js` | 她的协作状态机：看 → 决定 → 落笔/放图案/挪图案 → 冷却 |
| `lines.js` | 她的台词表：`LINES` 跟事件走，`CHAT` 是画板期间一直滚的日常闲聊（洗牌袋抽段） |
| `scene2.js` | 走廊、镜头推近、完成镜头、对白区（像素小人 + 对话框）、退出、图案面板、事件派发 |
| `tools/check.cjs` | 自检，截图落在 `tools/out/` |
| `tools/make-ghost-art.py` | 换主图画稿：`python act2/tools/make-ghost-art.py [源图]`，重出 `ghost-main.png` + `ghost-art.js` |
| `tools/ghost-demo.cjs` | 底稿演示：只有淡稿 → 描边框 → 加主图 → 全画完，出 `g1`–`g4` |
| `tools/end-demo.cjs` | 结尾演示：画满 → 完成 → 读结尾五句 → 出卡，出 `e3`–`e5` |
| `tools/ghost-preview.html` | 只渲染板面、不跑剧情，调底稿亮度时开这个 |
| `tools/shot-ghost.cjs` | 把上面那页截成 `out/ghost-only.png` |
| `tools/patterns-preview.html` | 图案放大预览（改图案时开这个看） |
| `tools/zoom.cjs` | 把任意截图局部放大：`node zoom.cjs out/03b-tidy.png 2.6 700 60` |

## 自检

```bash
node act2/tools/check.cjs
```

十八组断言：板面几何、底稿不算笔迹、底稿按区淡出、底稿开关与复位、画稿不越出主图区、
字幕一直在滚、对白区是两个像素小人且不压板、对白区高度不跟着字数变、
字幕内容是闲聊（六成以上不提画板）、四区互不误判、
图案面板与缩略图、图案放/拖/微调/撤销、橡皮删图案、文字工具真实路径、
她不覆盖已有笔迹、她的一笔可一次撤销、她自己放图案、她挪正挤在一起的图案、
导出 PNG、完成镜头用玩家作品、自然触发、刷新后存档恢复、中途退出与回来。

最后两条会真的把页面跳到 `../school-preview.html`，所以排在最后。

## 接进故事（已做）

模块现在真的接在故事里：第一幕手记打完后，`school-preview.html?start=1` 装进第一幕页面内的
全屏 `#storyframe`，之后黑板报、广播室、晚间广播、广播后的走廊都在这个框里继续走，
直到 `act4` 结尾靠栏杆的 CG。外层页面不换页，焦点交给框。

接线方式：

- 进入黑板视图：`school-preview.html` 跳到 `act2/blackboard.html?back=../school-preview.html`。
- 完成或离开时：完成卡的「继续 · 广播室」、先到这儿卡的「先去广播室」都跳到
  `act2/broadcast-bridge/index.html?board=done|deferred`。
- 广播室再过 `act3/broadcast.html?from=bridge`，最后到 `act4/after-broadcast/`。
- 第一幕的幕卡仍写「E 进入第二幕 / R 重看第一幕」；进入后不再跳页。

事件口仍然保留（`board:start` / `board:region` / `board:assist` / `board:leave` /
`board:quit` / `board:finish`），外面若再接别的宿主可以直接用。
